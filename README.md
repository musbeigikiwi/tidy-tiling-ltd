# Tidy Tiling Ltd

Modern Next.js website for Tidy Tiling Ltd.

## Current features
- Premium responsive homepage
- Slow moving hero and project imagery
- Services section
- Project gallery
- Before / after showcase
- Automatic client review slider
- Quote request form UI
- Mobile and iPad responsive design

## Next phase
- Supabase backend
- Secure admin login
- Quote request database
- Customer and project management
- Portfolio and review management
- Image uploads
- Site visit calendar
- Email notifications

## Run locally
```bash
npm install
npm run dev
```
